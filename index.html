v1lads Pin Scheduler is a private desktop automation project for organizing and scheduling original visual content for Pinterest accounts authorized by their owners.

01 / WHAT IT DOES

Publishing workflow

01

Prepare

Select each original image, destination board, title, description, optional link, and publishing time.

02

Schedule

Maintain a publishing queue in Google Sheets while keeping source image files on a local computer.

03

Publish

After authorization and API approval, submit the selected content through the Pinterest API and record its publishing status.

02 / ACCESS & SCOPE

User-authorized publishing

The planned integration uses OAuth authorization. The project does not request Pinterest passwords and is not intended for automated following, commenting, engagement manipulation, or scraping other users' private information.

This informational site does not provide a public account login or upload form. The application is currently in development.
