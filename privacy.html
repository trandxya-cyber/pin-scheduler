Privacy Policy

v1lads Pin Scheduler · Last updated: October 21, 2026

v1lads Pin Scheduler is a personal software project in development. This Privacy Policy explains how the project's informational website operates today and how the planned Pinterest publishing application is intended to handle information once it is activated. The public website does not offer account registration or Pinterest publishing services.

1. Who operates this project

Project name: v1lads Pin Scheduler.

Operator: an independent developer using the project name Trandxya Cyber. Trandxya Cyber is a personal project name, not a claim that a separate legal company is incorporated.

Contact for privacy inquiries: trandxya@gmail.com.

2. Information handled by this website

The website at trandxya-cyber.github.io/pin-scheduler/ is an informational, static website. It does not contain a contact form, application login, visitor analytics scripts or file upload feature. Visitors are not asked to provide Pinterest passwords or authorization tokens.

If you contact the operator by email, your email address and message will be used to respond to your inquiry and handle related follow-up. You may ask for that correspondence to be deleted by emailing the same address.

This website is hosted using GitHub Pages. GitHub may process technical information about website visits, such as IP addresses and request logs, under its General Privacy Statement.

3. Planned Pinterest application data

When the application is implemented and a Pinterest account is authorized by its owner, the intended publishing workflow may process the following information:

  • Pinterest account identifiers and identifiers of boards selected for publication;
  • image files individually selected by the operator, together with their filenames;
  • Pin titles, descriptions, optional destination links and scheduled publishing times;
  • Pin identifiers, publication statuses and error information returned by Pinterest; and
  • OAuth access and refresh tokens needed to maintain authorized Pinterest connections.

The application is not intended to request Pinterest account passwords or access accounts without the account owner's authorization.

4. Why this information is processed

The planned application is designed to publish content deliberately selected in advance, send it to the specified authorized Pinterest account and board, manage a publication schedule, and record the result. It is not intended to collect visitor profiles, sell personal data, scrape private Pinterest data, or automate engagement activities such as following, commenting or messaging.

5. Storage and service providers

Source images are intended to remain on the operator's Windows computer before being transmitted for an authorized Pin publication. A Google Sheets document is intended to hold the publishing queue and associated metadata. Pinterest will receive the selected image and publication details when the application creates a Pin.

The automation technology is still being selected and tested. The options being evaluated are self-hosted n8n and Make. If Make is used, the data submitted to that workflow will also be processed by Make. If self-hosted n8n is used, the automation will run on the operator's computer. This section will be updated to reflect the actual implementation before the publishing application is put into use.

The public GitHub repository for this website is not used to store Pinterest credentials, OAuth tokens, private publishing queues or local source images.

6. Retention and access

Emails sent to the operator are kept only while needed to reply and resolve related inquiries. Access to application credentials and publishing records is intended to be restricted to the operator and any administrators expressly authorized by the operator. The operational retention periods for OAuth tokens and publishing records will be specified once the application is deployed; no deployed retention schedule is represented here as already in effect.

7. Privacy requests and authorization revocation

For questions about information associated with this project, or to request access, correction or deletion of information held by the operator, contact trandxya@gmail.com. If Pinterest authorization is enabled, account owners will also be able to revoke permission through the applicable Pinterest account settings. Data processed by third-party services is additionally subject to their privacy policies.

8. Changes to this policy

This policy may be revised as the planned publishing application becomes operational or its data-handling arrangements change. The date shown above will be updated whenever this page is revised.
